# CIS-4375-Team-06-Spring-2025

Follow these steps to run the application:

1. Open the terminal and navigate to the CIS-4375-Team-06-Spring-2025 folder path.

2. Run the command "npm install" to install all dependencies.

3. Run the command "node server.js" to launch the server.

4. Go to http://localhost:8080 to view the website.
